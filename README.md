# Document Clustering using NLP and Word Embeddings

A Natural Language Processing project focused on comparing different text representation techniques for document clustering.

This repository is a reconstructed and cleaned implementation of the experiments conducted during my internship at the **Centre for Artificial Intelligence & Robotics (CAIR), DRDO, Bengaluru**.

## Project Overview

Analyzing a large collection of documents manually can be time-consuming, particularly when documents contain similar content, duplicates, or variations.

The objective of this project is to build a workflow for grouping similar documents automatically using Natural Language Processing and unsupervised machine learning.

The project compares four text representation techniques:

- Bag of Words (BoW)
- TF-IDF
- Word2Vec
- GloVe

The resulting document vectors are clustered using **K-Means Clustering** and evaluated using clustering performance metrics.

## Techniques Used

### Text Preprocessing

The documents are cleaned and normalized using NLP preprocessing techniques including:

- Lowercasing
- Tokenization
- Stopword removal
- Lemmatization
- Stemming

### Bag of Words

Bag of Words represents documents using the frequency of words appearing in each document.

### TF-IDF

TF-IDF represents documents by considering both the frequency of a term within a document and its importance across the complete document collection.

### Word2Vec

Word2Vec represents words as dense numerical vectors that capture relationships between words. Document-level vectors are generated by averaging the vectors of words present in each document.

### GloVe

Pre-trained GloVe embeddings are used to obtain semantic word representations. Individual word vectors are combined to obtain document-level representations.

### Co-occurrence Matrix

The project also explores word co-occurrence relationships using:

1. Standard co-occurrence counts.
2. Distance-weighted co-occurrence, where nearby words receive greater weight.

For the distance-weighted method:

```text
weight = 1 / distance
```

### K-Means Clustering

K-Means is used to group documents based on their vector representations.

The Elbow Method can be used to examine different values of K.

### PCA

Principal Component Analysis is used to reduce high-dimensional document vectors to two dimensions for visualization.

## Evaluation Metrics

Two unsupervised clustering metrics are used:

**Silhouette Score**

Measures how similar a document is to its own cluster compared with other clusters. Higher values generally indicate better-defined clusters.

**Davies-Bouldin Index**

Measures within-cluster dispersion relative to separation between clusters. Lower values generally indicate better-separated clusters.

## Internship Experiment Results

The original internship experiments reported the following results:

| Representation | Clusters | Silhouette Score | Davies-Bouldin Index |
|---|---:|---:|---:|
| Bag of Words | 3 | 0.0915 | 0.5515 |
| TF-IDF | 3 | 0.5791 | 0.6115 |
| Word2Vec | 3 | 0.0505 | 0.5769 |
| GloVe | 2 | 0.2259 | 1.0378 |

In the internship experiments, TF-IDF produced the highest Silhouette Score among the evaluated representations.

These values correspond to the original internship experiments. Results produced by the reconstructed demonstration dataset in this repository may differ.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/document-clustering-nlp.git
cd document-clustering-nlp
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

Run:

```bash
python main.py
```

The program loads the sample documents, preprocesses the text, generates document representations, performs K-Means clustering, and reports clustering evaluation metrics.

The GloVe model is downloaded automatically through Gensim when it is used for the first time, so an internet connection is required for the initial download.
